# 초기 데이터 CSV 로드 가이드

`docs/initial_data_set_need_change_provider_id.csv` 파일을 Postgres/PostGIS 환경에 반영하는 절차입니다. Docker(PostGIS 컨테이너)를 기준으로 설명합니다.

## 1. 사전 점검 체크리스트

1. **문자 인코딩**: 원본 CSV가 CP949(EUC-KR)일 가능성이 높습니다. Postgres `COPY` 기본 인코딩인 UTF-8로 변환합니다.
2. **좌표계 확인**: `lat`, `lng` 값이 EPSG:5174(중부원점 TM) 좌표이며, 컬럼명이 실제 축과 반대로 저장되어 있습니다(`lat`=Easting, `lng`=Northing). 변환 시 축을 바꿔 `ST_MakePoint(lat, lng)`으로 처리합니다.
3. **JSON 문자열 정합성**: `working_hours`, `break_time` 필드의 따옴표가 중복되어 있어 JSON 파싱이 실패할 수 있습니다. 사전 정제가 필요합니다.
4. **필수 컬럼 매핑**: `places` 테이블은 `opened_at_source`, `category`(text[]), `location` 등 추가 필드가 있어 기본값/가공 로직을 준비해야 합니다.
5. **중복 처리 전략**: `provider_id` 기준으로 중복 시 업데이트할지 무시할지 정책을 결정합니다.

## 2. 데이터 정리

### 2.1 UTF-8로 인코딩 변환

```bash
iconv -f CP949 -t UTF-8 \
  docs/initial_data_set_need_change_provider_id.csv \
  > /tmp/initial_places_utf8.csv
```

### 2.2 JSON 문자열 정리 예시

```bash
cat /tmp/initial_places_utf8.csv \
  | python3 - <<'PY'
import csv, json, sys
reader = csv.DictReader(sys.stdin)
fieldnames = reader.fieldnames
writer = csv.DictWriter(sys.stdout, fieldnames=fieldnames)
writer.writeheader()
for row in reader:
    for key in ("working_hours", "break_time"):
        raw = row[key]
        if raw:
            row[key] = json.dumps(json.loads(raw))
    writer.writerow(row)
PY
  > /tmp/initial_places_clean.csv
```

위 스크립트는 잘못된 따옴표를 교정하여 유효한 JSON 문자열로 만들어 줍니다.

## 3. Staging 테이블 및 반영 SQL

먼저 스테이징 테이블을 생성합니다.

```bash
docker exec -i db-postgis \
  psql -U devuser -d matjom_dev \
  -c "DROP TABLE IF EXISTS staging_initial_places;" \
  -c "CREATE TABLE staging_initial_places (
    provider_id TEXT,
    opened_at DATE,
    biz_status TEXT,
    phone_number TEXT,
    name TEXT,
    updated_at DATE,
    category TEXT,
    lat NUMERIC,
    lng NUMERIC,
    working_hours JSONB,
    break_time JSONB,
    addr_sido TEXT,
    addr_sigungu TEXT,
    addr_road TEXT,
    addr_bnum TEXT,
    addr_detail TEXT,
    addr_dong TEXT
  );"
```

그 다음, 본 테이블 반영용 SQL(`sql/import_initial_places.sql`)을 작성합니다.

```sql
INSERT INTO places (
    name, lat, lng, category, provider_id,
    phone_number, working_hours, break_time, opened_at,
    opened_at_source, biz_status,
    addr_sido, addr_sigungu, addr_eupmyeondong, addr_street, addr_detail,
    location
)
SELECT
    s.name,
    ST_Y(geom_wgs84),
    ST_X(geom_wgs84),
    ARRAY[trim(s.category)]::text[],
    s.provider_id,
    s.phone_number,
    COALESCE(s.working_hours, '{}'::jsonb),
    COALESCE(s.break_time, '[]'::jsonb),
    s.opened_at,
    jsonb_build_object('source', 'initial_csv', 'updated_at', s.updated_at),
    s.biz_status,
    s.addr_sido,
    s.addr_sigungu,
    s.addr_dong,
    COALESCE(concat_ws(' ', s.addr_road, s.addr_bnum), ''),
    COALESCE(s.addr_detail, ''),
    geom_wgs84
FROM (
    SELECT
        sp.*,
        ST_Transform(
            ST_SetSRID(ST_MakePoint(sp.lat, sp.lng), 5174),
            4326
        ) AS geom_wgs84
    FROM staging_initial_places sp
) s
ON CONFLICT (provider_id)
DO UPDATE SET
    name = EXCLUDED.name,
    lat = EXCLUDED.lat,
    lng = EXCLUDED.lng,
    category = EXCLUDED.category,
    phone_number = EXCLUDED.phone_number,
    working_hours = EXCLUDED.working_hours,
    break_time = EXCLUDED.break_time,
    opened_at = EXCLUDED.opened_at,
    opened_at_source = EXCLUDED.opened_at_source,
    biz_status = EXCLUDED.biz_status,
    addr_sido = EXCLUDED.addr_sido,
    addr_sigungu = EXCLUDED.addr_sigungu,
    addr_eupmyeondong = EXCLUDED.addr_eupmyeondong,
    addr_street = EXCLUDED.addr_street,
    addr_detail = EXCLUDED.addr_detail,
    location = EXCLUDED.location,
    updated_at = now();
```

> 좌표계가 이미 WGS84라면 `ST_SetSRID(ST_MakePoint(...), 4326)`까지만 사용하세요.

## 4. Docker Postgres에 로드하기

### 4.1 쉘 스크립트로 원클릭 실행

`scripts/import_initial_places.sh`는 위 절차(인코딩 변환 → JSON 정리 → 컨테이너 복사 → 스테이징 로드 → 본 테이블 반영 → ANALYZE)를 한 번에 수행합니다. 저장소 루트에서 실행하세요.

```bash
./scripts/import_initial_places.sh docs/initial_data_set_need_change_provider_id.csv
```

환경 변수 `POSTGIS_CONTAINER`, `POSTGIS_DB`, `POSTGIS_USER`를 설정하면 기본값(`db-postgis`, `matjom_dev`, `devuser`) 대신 사용할 수 있습니다.
- 스크립트는 스테이징 테이블 재생성, CSV 로드, `provider_id` UNIQUE 제약 보장, 주요 컬럼 타입 보정(`provider_id` 100자, `addr_eupmyeondong` 80자), 본 테이블 반영, `ANALYZE`까지 순차 실행합니다.
- 좌표계는 EPSG:5174 → WGS84(4326)로 자동 변환됩니다.

### 4.2 수동 실행(직접 커맨드 실행을 원하는 경우)

#### 1) CSV 컨테이너로 복사

```bash
docker cp /tmp/initial_places_clean.csv db-postgis:/tmp/initial_places_clean.csv
```

#### 2) Staging 테이블에 CSV 로드 (psql `\copy`)

```bash
docker exec -i db-postgis \
  psql -U devuser -d matjom_dev \
  -c "\copy staging_initial_places FROM '/tmp/initial_places_clean.csv' WITH (FORMAT csv, HEADER true)"
```

#### 3) 본 테이블 반영

```bash
cat sql/import_initial_places.sql | \
docker exec -i db-postgis \
  psql -U devuser -d matjom_dev -f -
```

#### 4) 통계 갱신

```bash
docker exec -i db-postgis \
  psql -U devuser -d matjom_dev \
  -c "ANALYZE places;"
```

## 6. 문제 해결 팁

- **인코딩 오류**: `iconv` 변환 후에도 깨진다면 원본 CSV 인코딩을 재확인하고, `nkf`, `recode` 등을 사용합니다.
- **JSON 파싱 실패**: Python 정제 스크립트에서 문제 행을 로그로 남겨 수동 수정합니다.
- **좌표 변환**: 제공처 좌표계가 5179가 아닌 다른 값일 수 있으니 공식 문서를 확인하고 EPSG 코드를 변경하세요.
- **중복 데이터**: `ON CONFLICT` 정책을 `DO NOTHING`으로 바꾸면 덮어쓰지 않고 무시합니다.
- **대량 데이터**: 수십만 건 이상이면 `maintenance_work_mem`, `checkpoint_segments` 등의 파라미터를 조정하거나 배치를 분할하여 진행하세요.
