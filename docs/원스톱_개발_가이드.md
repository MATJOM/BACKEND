# MATJOM Back-end 원스톱 개발 가이드

처음 저장소를 클론했을 때 바로 개발을 시작할 수 있도록 필요한 환경 설정과 실행 절차를 정리했습니다.

## 1. 필수 도구 설치

- **Java 21** (SDKMAN, Azul Zulu 등)
- **Gradle Wrapper**: 저장소에 포함되어 있으므로 별도 설치 불필요
- **Docker & Docker Compose**: Postgres/PostGIS · Redis 등 인프라 실행용
- (선택) IntelliJ IDEA 또는 VS Code Spring 플러그인

## 2. 저장소 클론

```bash
git clone https://github.com/MATJOM/BACKEND.git
cd BACKEND
```

## 3. 환경 변수 설정

운영/개발 환경에서 사용할 비밀 값은 `.env`에 두고 애플리케이션 실행 시 로드하세요. 기본 개발 프로필(dev)은 예시 계정(devuser/devpass, redis localhost)을 사용하므로 추가 설정이 필요 없습니다.

```bash
cp .env.example .env   # 존재한다면 참고용 복사
```

## 4. 로컬 인프라 기동

`infra/` 디렉터리에 서비스별 Docker Compose 파일이 있습니다.

```bash
# PostGIS + Redis
docker compose -f infra/postgresql/docker-compose.yml up -d
docker compose -f infra/redis/docker-compose.yml up -d

# (옵션) 모니터링, ELK 등 필요 시 추가 실행
```

컨테이너 상태 확인: `docker ps --format '{{.Names}}	{{.Status}}'`

## 5. 애플리케이션 실행

### 개발 프로필 (Postgres/PostGIS 사용)

```bash
SPRING_PROFILES_ACTIVE=dev GRADLE_USER_HOME=.gradle ./gradlew bootRun
```

`application-dev.yml`은 `schema-postgres.sql`을 자동 적용하고, `ddl-auto=validate`로 스키마를 검증합니다.

### 로컬(H2) 프로필

외부 인프라 없이 빠르게 실행하려면 `local` 프로필을 사용하세요.

```bash
SPRING_PROFILES_ACTIVE=local ./gradlew bootRun
```

## 6. 테스트 실행

테스트는 Testcontainers 기반 PostGIS(16-3.4 이미지)를 사용합니다. Docker가 실행 중인지 확인하세요.

```bash
GRADLE_USER_HOME=.gradle ./gradlew test
```

## 7. IDE 설정 팁 (IntelliJ 기준)

1. `File > New > Project from Existing Sources`로 프로젝트를 열면 Gradle 설정이 자동 인식됩니다.
2. `Run/Debug Configurations`에서 Spring Boot 구성 추가 → `Main class`에 `com.matjom.matjom.MatjomApplication`, `Active Profiles`에 `dev` 또는 `local` 입력.
3. DevTools가 포함되어 있으므로 코드 수정 시 자동 리스타트됩니다.

## 10. FAQ

- **PostGIS 확장이 없다는 오류**: Docker 컨테이너(`postgis/postgis:16-3.4`)를 사용하면 자동으로 설치됩니다. 별도 DB를 사용할 경우 `CREATE EXTENSION postgis;` 실행 필요.
- **Testcontainers 속도 문제**: 로컬 Docker 데스크톱 설정에서 리소스를 늘리거나, `~/.testcontainers.properties`로 이미지 캐싱을 활성화하세요.
- **소프트 삭제 엔티티 조회**: Repository 쿼리에 `deleted_at IS NULL` 조건을 추가하거나 `@Where`를 사용합니다.
